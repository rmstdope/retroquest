# RetroQuest: A Text Adventure Built with AI

Welcome to RetroQuest, a (as the name may give away) retro inspired text adventure game!

## How to Play

### Starting the game

RetroQuest runs in the browser. From a checkout:

```bash
npm install --prefix web
npm run dev
```

This opens the game at `http://localhost:5173`. The game engine and all acts are TypeScript (see `web/README.md`); they started out in Python and were ported in October 2026 (`docs/typescript-engine-plan.md`).

### Commands

The game supports a variety of commands to navigate and interact with the world. However, the only command you will need to use to complete the game is:

```
help
```

This command will show you the list of all available commands in the game. You can also use the `?` command as a shortcut for `help`.
