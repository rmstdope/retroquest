Option B — proven wording, plus signature and watermark

The shared style text every RetroQuest image starts from, as the studio shows it. Red is taken out, green is added.

Shared style

Painted storybook illustration of a place in a small medieval fantasy world, soft gouache with visible brush texture, muted warm tones, gentle lantern lightsoft warm light and long soft shadows, hand-painted and slightly worn like an old picture book, one single full-bleed image with no fold, frame or border, no text, lettering, signature or watermark anywhere, wide landscape composition

What each change is for

  • lantern light → warm light: the field, the well and every other room stop getting a lantern they don't have.
  • old picture book removed: no open book with a fold down the middle, no frayed corners.
  • no fold, frame or border: one picture edge to edge.
  • no text or lettering: the image models never read the “keep out” list, so this has to be in the style itself.
  • signature or watermark: named outright, as the request asks for “no signature”.

Names signatures and watermarks too. Those two words were not in the test, so the first images made from it may need a second look.
