rq-x17s — The menus' screens work with the arrow keys and Enter

Agreed: the title page's cream ring marks the selected thing. In Settings, ↑ ↓ move between rows and ← → change a row. Save slots follow the grid. The arrows wrap round at the ends. Escape goes back, and a key line (keyboard players only) says so. Moving the ring plays the glass ting. Choosing or flipping a switch plays the brass latch. Changing a value with ← → plays the ting.
