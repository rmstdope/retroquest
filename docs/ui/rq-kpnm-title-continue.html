The title page

Option A — the title page offers Continue, New game and Load game

The pattern almost every game uses. When there are saves, the title page leads with Continue: one press takes the player straight back into their most recent save (the quick save or a slot, whichever is newer), with where it is printed under the word. New game and Load game sit beneath it. With no saves, the title page is exactly what it is today.
