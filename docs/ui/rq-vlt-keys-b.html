Option B — recommended

In the command box, Esc still skips

Space types and Enter gives the command, as today. Esc first closes the word list if it is open; pressed again (or with no list open) it skips the rest of the reading, keeping what was typed. While the cursor is in the box the hint under the story reads “Esc to skip” instead of “Space to hurry · Esc to skip”.

Recommended: Esc as “dismiss the thing on top” is the common pattern, and it keeps the hint truthful. Cost: one more meaning for Esc in the box.
