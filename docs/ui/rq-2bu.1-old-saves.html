Option A — an Act IV save from before the change is refused with the game's existing load-failure line

A save made anywhere in Act IV today remembers every Act IV room, including the two being cut. Once they are gone, that save no longer matches the game. Saves made in Acts I–III are not affected either way.

Loading an older Act IV save

> load fortress

Failed to load game: The save contains an unknown class: RoyalGardens

This is the line the game already shows today for a save it can't read. Nothing new is written. The player can still start Act IV again from the Fortress Gates.

On a phone

> load fortress

Failed to load game: The save contains an unknown class: RoyalGardens

Wraps as one line; no other change.
