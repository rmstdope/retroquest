rq-v29l.13 — agreed: the ring offers only what a thing answers to; Open reads books, letters, notes and maps.

only what the thing answers to

The ring shows Open only on things that can be opened (and on things you read). Close is gone everywhere: nothing in the game can be closed.

The ring is shorter and every button does something. A thing that only opens later in the story still shows Open from the start, so the ring never hints at a puzzle's answer.

Open sits beside Use; both read

On a thing you read (the journal, the mother's letter, the father's note) Open is added and reads it, exactly as Use already does.

Use stays on every thing, as everywhere else in the game. Two buttons do the same thing on these few items.

the same, plus maps

Unfolding a map counts as opening it, so maps get Open too and Open shows the map, as Use does.

Open says exactly what reading it says today

Pressing Open on the letter shows the same words as pressing Use (or Examine, for the books that are read that way).

› open mother's letter
mother's letter reads …
(the letter's words, unchanged)
› use mother's letter
mother's letter reads …
(the letter's words, unchanged)

Nothing new for the narrator to record.

the refusal names it as the story does

Typing a refusal (the ring no longer offers it) names the thing the way the narration does.

› close mother's letter
You can't close the mother's letter.
› close journal
You can't close Elior's Journal. (a name, so it stays capitalised)
