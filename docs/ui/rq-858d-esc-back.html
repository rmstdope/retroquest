Esc back to verbs

Esc steps back from the command box to the verbs Agreed

Each Esc takes one step back: close the word list, then clear the typed text, then leave the box for the verbs with focus on the verb used last. Tab keeps doing word completion only. While the cursor is in the command box, the Actions button carries a small Esc mark (not on touch screens). The same rule holds in the narrow window's pull-up panel.
