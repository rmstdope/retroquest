# rq-306j: a menu e2e spec failed twice on CI, green locally

## What happened
- `e2e/menuKeys.spec.ts:76` ("Help scrolls with the keys") failed on its first attempt in `web-e2e (2/3)` on head 089f8c1a, twice in a row (15.9 s, then passes on retry). `failOnFlakyTests` makes a pass-on-retry red. The same job passed on the previous head, which differs only by a unit-test file, and passed on a third run of the same head.
- Locally it failed once in three runs under 10 busy loops, then passed 12 times (with and without the new polygon clip). No cause found.
- Earlier in the pass the worktree's `node_modules` lost packages (`vue-tsc`, then others) between two commands, so `npm run build` and `playwright` died with exit 127 until `npm ci` was run again.
- A blanket `prettier --write src/lantern/*.ts` reformatted two files the bead did not change (the installed prettier 3.10.1 differs from the one CI formats with).

## Why
Not established for the spec. The `node_modules` loss: not established. The prettier drift: `^3.8.3` in `web/package.json` resolves to a newer prettier than CI's lockfile.

## Cost
About 25 minutes: two bare CI re-runs spent on one head, and one local investigation.

## Prevent by
Run prettier only on the files the diff changed (`git diff --name-only | xargs npx prettier --write`); not established for the rest.
